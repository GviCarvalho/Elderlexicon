# Apêndice C: Medidas e números de referência

Os números que um mago precisa saber de cor, ou ter à mão. Entre parênteses, o capítulo onde cada um é explicado.

## As medidas

| Medida | Valor |
|---|---|
| grão | a menor parte da matéria, de um só elemento; não se divide (2) |
| UMU | 256 grãos (2) |
| sar | um cubo de mais ou menos um passo de lado (2) |
| um sar de matéria solta (terra fofa, areia, água, ar, fogo) | 4096 grãos, 16 UMU (2) |
| uma camada | 256 grãos, 1 UMU: um objeto pequeno de mão (2) |
| o empacotamento | pedra 3× (12 288 grãos, 48 UMU); ferro 10× (40 960, 160 UMU); obsidiana 100× (409 600, 1600 UMU) (2) |
| um lingote de ferro | um nono de sar de ferro: ~4550 grãos, ~18 UMU (2) |
| o cerne | cem partes, divididas entre os quatro (2, 9) |

## O corpo

| | Valor |
|---|---|
| o cálice de vis, em todo ser vivo | 100, sempre (3) |
| corpo humano | ~100 UMU: 55 de água, 38 de ar, 5 de terra, 2 de fogo (3) |
| uma pessoa inteira | ~200 UMU: o corpo e o cálice (3) |
| corpo gris | ~60 de terra, 20 de água, 15 de ar, 5 de fogo (3) |
| a saúde | segue o elemento que mais falta (3) |
| vida de um ser criado | o corpo dividido por 5 (23) |

## O tempo

| | Valor |
|---|---|
| o transe | 2 segundos; cabem de 2 a 4 palavras (11) |
| uma coluna da página | 1/4 de segundo (13) |
| um acontecimento vale | no último segundo (19) |
| um "enquanto" se repete | a cada segundo, pagando cada vez (19) |
| a duração padrão do `impediunt`, da revelação, da ilusão, da visão | 2 segundos (7, 18) |
| uma lâmina invocada que não é sólida | 2 segundos depois de entregue (21) |

## Os custos

| | Custo |
|---|---|
| uma chama (`igni vocant`) | ~0,3 UMU (6) |
| um sar de matéria (`vocant` sem número) | 16 UMU (7) |
| o empurrão padrão (`iactare`) | 10 UMU (7) |
| converter | 5% por degrau da escada; da vis, grátis; para a vis, 15% (9) |
| condensar o que vem do mundo | perto de 10% da energia; leva de meio segundo a 5 segundos (14) |
| revelar | 0,1 UMU por sar de alcance, por segundo; 16 sar por 2 s ≈ 3,2 UMU (18) |
| uma ilusão | um décimo da matéria que mostra (18) |
| ver pelos olhos de outro | ~0,5 UMU por segundo (18) |
| projetar o espírito | ~0,05 UMU por sar, por segundo (18) |
| ficar invisível | uma pessoa, por 30 segundos: ~30 UMU (18) |
| viver num corpo sem kern | 1 UMU por segundo (23) |
| mover uma coisa pela marca | o verbo, mais o peso vezes a distância (16) |
| um círculo pela marca, longe | o custo × (1 + distância ÷ 64) (20) |
| um vínculo de integridade | a vida movida × 5 UMU, a cada reflexo (17) |
| criar um ser | o cálice inteiro, 100 de vis, mais o corpo (23) |

## As áreas e os alcances

| | Valor |
|---|---|
| a mira, sem `ubis` | até uns 12 sar (7) |
| o raio do `impediunt` | 3 × √(UMU ÷ 10): 10 UMU, raio 3; 40, raio 6; 90, raio 9 (7) |
| a revelação, sem número | 16 sar (18) |
| a projeção | até 16 sar de onde o espírito surge (18) |
| as peças de um círculo | a até 3 sar umas das outras (20) |
| um ser criado | energias a até ~2,5 sar umas das outras, no mesmo instante (23) |

## A concentração

| Num só ponto | Acontece |
|---|---|
| fogo: mais de uma chama | um ponto quente, que derrete pedra (14) |
| fogo: ~30 chamas (~10 UMU) | plasma: estoura como raio (14) |
| terra: até ~40 UMU | terra (6, 14) |
| terra: ~48 UMU | pedra (6, 14) |
| terra: 64 a 640 UMU | ardósia (6, 14) |
| terra: ~720 UMU ou mais | obsidiana; além, um poço de gravidade (6, 14) |
| terra: ~32 000 UMU | um buraco negro (14) |
| água: ~160 UMU | gelo de pressão (6, 14) |
| ar: ~960 UMU | bomba de pressão (6, 14) |
