# Apêndice D: Códigos conhecidos

Os códigos que esta casa mediu, em partes de cem: **terra / água / ar / fogo**. Uma mistura perto de um destes códigos
é a coisa (capítulo 2); um cerne mudado para um deles a transforma nela (capítulo 9); um corpo perto de uma destas
proporções, preso a um cálice, é o ser (capítulo 23).

Três avisos antes da tabela:

- **Os códigos não bastam sozinhos.** O que uma coisa é também depende de quão apertados estão os seus grãos (capítulo
  2): terra pura apertada como a pedra é pedra.
- **As coisas marcadas com ✦ nascem dentro de outras**, como o minério na rocha, e **as marcadas com ✋ só mãos fazem**.
  Nenhuma delas aparece por chegar perto do código: pedem o código exato (capítulos 2 e 21).
- **Esta lista é muito menor que o mundo.** Se você medir um código novo, traga-o para esta casa (capítulo 25).
